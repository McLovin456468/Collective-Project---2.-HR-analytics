# Проект: Прогнозирование удовлетворённости и оттока сотрудников

## 1. Назначение и цель проекта

Компания стремится оптимизировать управление персоналом, избежать финансовых потерь и снизить отток сотрудников. Уровень удовлетворённости работой напрямую влияет на вероятность увольнения, однако сбор данных через опросы трудоёмок и требует полного охвата персонала.

**Цель проекта:** построить две модели машинного обучения:

1. **Модель 1** — предсказание уровня удовлетворённости сотрудника работой в компании (регрессия).
2. **Модель 2** — предсказание факта увольнения сотрудника из компании (бинарная классификация).

**Целевые требования к качеству:**
- Задача 1: **SMAPE ≤ 15** на тестовой выборке.
- Задача 2: **ROC-AUC ≥ 0.91** на тестовой выборке.

---

## 2. Задача 1: Предсказание уровня удовлетворённости сотрудника

### 2.1. Входные данные

| Файл | Содержание |
|------|------------|
| `train_job_satisfaction_rate.csv` | Обучающая выборка (признаки + целевой признак) |
| `test_features.csv` | Входные признаки тестовой выборки |
| `test_target_job_satisfaction_rate.csv` | Целевой признак тестовой выборки |

### 2.2. Описание признаков

| Поле | Описание |
|------|----------|
| `id` | уникальный идентификатор сотрудника |
| `dept` | отдел |
| `level` | уровень должности |
| `workload` | уровень загруженности |
| `employment_years` | длительность работы в компании (годы) |
| `last_year_promo` | повышение за последний год (да/нет) |
| `last_year_violations` | нарушения трудового договора за последний год |
| `supervisor_evaluation` | оценка руководителя |
| `salary` | ежемесячная зарплата |

### 2.3. Целевой признак

| Поле | Описание |
|------|----------|
| `job_satisfaction_rate` | уровень удовлетворённости (0 — полностью неудовлетворён, 1 — полностью удовлетворён) |

### 2.4. Этапы выполнения

#### 2.4.1. Загрузка и предобработка данных
- Загрузить обучающую и тестовую выборки.
- Выполнить анализ пропусков, дубликатов, типов данных.
- При необходимости выполнить предобработку (пропуски заполнять в пайплайне).

#### 2.4.2. Исследовательский анализ данных (EDA)
- Исследовать распределения всех признаков.
- Выявить взаимосвязи с целевым признаком.
- Сформулировать выводы о необходимых преобразованиях.

#### 2.4.3. Подготовка данных (пайплайн)
- Подготовку признаков выполнить в **пайплайне**.
- Использовать **ColumnTransformer** для раздельной обработки количественных и категориальных признаков.
- Для кодирования категориальных признаков применить **не менее двух кодировщиков** (например, OneHotEncoder, OrdinalEncoder).
- Для масштабирования количественных признаков применить скейлер (при необходимости).

#### 2.4.4. Обучение моделей
Обучить **как минимум две модели**:
- одна **линейная** модель (например, LinearRegression, Ridge, Lasso);
- одна **дерево решений** (DecisionTreeRegressor, RandomForestRegressor, GradientBoostingRegressor).

Подобрать гиперпараметры как минимум для одной модели с помощью `GridSearchCV` или `RandomizedSearchCV`.

#### 2.4.5. Метрика оценки — SMAPE

Реализовать функцию расчёта **SMAPE** (Symmetric Mean Absolute Percentage Error):

```
SMAPE = (100 / n) * Σ |y_i - ŷ_i| / ((|y_i| + |ŷ_i|) / 2)
```

Использовать SMAPE для:
- подбора гиперпараметров;
- оценки качества моделей на валидационной и тестовой выборках.

**Критерий успеха:** SMAPE ≤ 15 на тестовой выборке.

#### 2.4.6. Выбор лучшей модели и выводы
- Сравнить модели по метрике SMAPE.
- Выбрать лучшую модель для задачи 1.
- Сохранить предсказания лучшей модели для использования в задаче 2.

## 3. Задача 2: Предсказание увольнения сотрудника

| Файл | Содержание |

| `train_quit.csv` | Обучающая выборка (признаки + целевой признак увольнения) |

| `test_target_quit.csv` | Целевой признак тестовой выборки (факт увольнения) |

**Дополнительный признак:** предсказанный `job_satisfaction_rate` из лучшей модели задачи 1 добавляется к входным признакам.

### 3.2. Целевой признак

| Поле | Описание |
|------|----------|
| `quit` | факт увольнения сотрудника (бинарный признак) |

### 3.3. Этапы выполнения

#### 3.3.1. Загрузка и предобработка данных
- Загрузить обучающую и тестовую выборки.
- Выполнить предобработку (пропуски заполнять в пайплайне).

#### 3.3.2. Исследовательский анализ данных

- Составить **портрет уволившегося сотрудника**:
  - распределение по отделам;
  - уровень загруженности;
  - средняя зарплата (ушедшие vs оставшиеся);
  - другие значимые различия.
- Проверить гипотезу: уровень удовлетворённости (`job_satisfaction_rate`) влияет на увольнение.
  - Визуализировать распределение `job_satisfaction_rate` для ушедших и оставшихся сотрудников.
  - Использовать данные с обоими целевыми признаками.

#### 3.3.3. Добавление нового признака
- Добавить к входным признакам `job_satisfaction_rate`, предсказанный лучшей моделью задачи 1.

#### 3.3.4. Подготовка данных (пайплайн)

#### 3.3.5. Обучение моделей
Обучить **как минимум три модели** (например, LogisticRegression, RandomForestClassifier, GradientBoostingClassifier, LightGBM, CatBoost).

Подобрать гиперпараметры **как минимум для двух моделей**.

#### 3.3.6. Метрика оценки — ROC-AUC
- Основная метрика: **ROC-AUC**.
- **Критерий успеха:** ROC-AUC ≥ 0.91 на тестовой выборке.
- При необходимости применить отбор признаков для улучшения метрики.

#### 3.3.7. Выбор лучшей модели и выводы

- Выбрать лучшую модель для задачи 2.
- Проанализировать, какие признаки наиболее важны для предсказания увольнения.
